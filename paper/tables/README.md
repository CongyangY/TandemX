# Table 1. Included complete raw HiFi libraries

`input_cohort.tsv` is derived from completed, archived QC receipts for ten
included libraries from eight reported species. It contains exact run IDs, read/base totals, length
statistics, GC/N summaries, duplicate archive-ID counts, raw-file SHA-256 and
the source QC receipt/hash for each row. Total included sequence is
262,731,255,175 bp in 14,937,608 reads. Values describe these included files, not complete studies,
independent biological replicates or true nuclear sequencing coverage.

The species/material labels come from the curated source records; no taxonomic
classification of individual reads is implied. Reported Phred summaries and
exact source sample/batch/assembly limitations remain in each evidence folder.
The source integrity and whole-file status must accompany reuse of these counts.

Other manuscript tables currently point to the complete benchmark evidence
tables listed in `../manuscript.md`. Final standalone numbering, harmonized
column presentation and publication workbook export remain to be completed.
