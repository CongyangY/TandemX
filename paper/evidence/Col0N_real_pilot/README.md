# Col-0N whole-library random 11.766-Mb pilot

Complete-source QC and seeded sampling preceded this experiment. Exact input:
752 reads / 11,765,868 bases, seed6101 sample_001 from ERR6210723. These are
reads from a pooled Col-0N library, not 752 specimens. Source b53a193;
elastic/sequence clustering and exact-related family audit are explicit options.

All three tools completed and normalized successfully. Seconds / peak MiB:
TandemX 17.520 / 89.47; TRF 12.981 / 125.34; TideHunter 4.247 / 254.58.
Timings overlapped data acquisition/other jobs and are diagnostic. Calls and
union fractions are descriptive; independent real repeat truth is not supplied.
These values do not establish sensitivity, precision or overall superiority.

Unchanged compact source receipts are listed in `archive_manifest.json`.
Native outputs/normalized calls remain at the T7 paths in those receipts.
