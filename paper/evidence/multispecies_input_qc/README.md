# Ten-library cross-cohort input QC

## Figure contract

Analytical question: do the ten checksum-validated HiFi libraries span enough
data volume and read-distribution diversity that later cross-species benchmarks
cannot be mistaken for one homogeneous input type? The supported takeaway is
that input amount, read length, GC composition and reported read-quality
distributions differ materially among the included libraries; the figure does
not measure biological accuracy, independent replication or repeat truth.

The current static six-panel supplement uses all 14,937,608 reads and 262,731,255,175 bp
represented by full-file QC histograms. Panels A-C show total bases, paired
median/N50 read lengths and whole-file GC fraction. Panels D-F are row-normalized
heatmaps for read length (2-kb bins, final bin at least 80 kb), GC (2-percentage-
point bins, terminal bins include values outside 20-70%) and mean reported read
quality (5-Phred bins, final bin at least 60). Every heatmap cell retains its read
denominator in `panel_source.tsv`.

The renderer is Matplotlib because this is a versioned PDF/SVG/PNG manuscript
artifact. Library order is deterministic by reported species then material.
Panels A-C use direct labels and a colorblind-safe categorical palette; panels
D-F use a perceptually ordered viridis scale plus row labels, so identity never
depends on color. Final QA requires readable labels in the PDF/PNG, editable SVG
text, no raster nodes in SVG, exact source/provenance hashes and visual inspection
at manuscript size.

Outputs are generated by `benchmarks/scripts/plot_multispecies_input_qc.py`.
Large raw reads are not copied into this directory.

`figures_v2/` is the current inspected manuscript render. Its provenance
reconciles 10 libraries, 8 reported species, 14,937,608 reads and
262,731,255,175 bp. The PDF, SVG and PNG hashes match the receipt; the SVG
contains 110 editable text nodes and no raster image node. The PDF was rendered
to PNG and visually inspected at manuscript size with no clipped or overlapping
labels. `figures_v1/` remains the historical nine-library render.
