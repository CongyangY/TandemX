# Quantify calibration development evidence

This compact archive retains the complete three-genome, 108-execution public-command matrix, 5,940 family rows, controls, source/config hashes, per-execution artifact hashes and a recomputed development decision. The oracle error rate is not blind, control selection uses simulation truth, and the diagnostic spread is not a sampling confidence interval. The post-hoc depth-gated control rule is a candidate for a future frozen held-out test; it is not promoted here.
