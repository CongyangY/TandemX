# tidecluster_factorial_validation_v1

This compact archive retains the frozen configuration, exact attempted stage, external-process logs, source snapshot and host/container resource records. Execution failed before accuracy evaluation, so no figure or accuracy summary is present and unavailable measurements remain missing rather than zero.

The three 10-Mb genomes are same-process simulations and the seeds were already consumed for TandemX quantification validation. TideCluster settings were frozen before its outputs were inspected, but the runs are technical comparisons rather than independent biological replicates.
