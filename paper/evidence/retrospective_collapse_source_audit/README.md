# Retrospective collapse source audit

These are exact ENA Portal API read-run reports retrieved on 2026-09-07 for four candidate improved-assembly studies. `selected_pacbio_wgs_runs.tsv` filters only PACBIO_SMRT genomic WGS rows without inferring that every archive filename labelled `subreads` contains raw continuous long reads; experiment titles and the source papers identify the CCS/HiFi role.

The metadata confirm accessions and reported sequencing platform. They do not establish that historical and improved assemblies used the identical DNA extraction, plant individual, seed stock, or BioSample. Current candidates are therefore material/cultivar-matched retrospective tests until assembly BioSample and study methods prove a stronger tier. No donor-matched collapse truth is claimed by this archive.
