# Independent source screen, 2026-09-18

This is a **source-enrollment screen, not validation**. No new sample cluster
was frozen, no read predictions were opened, and no biological accuracy claim
follows. Accession/individual, extraction, assembly provenance, source checksums
and an eligible simple/complex array pair must be verified before enrollment.
