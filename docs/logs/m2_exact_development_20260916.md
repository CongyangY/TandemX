# M2 local architecture prototype: exact-sequence development record

Date: 2026-09-16. This is an internal-disk, exact synthetic development run.
The input is generated by `benchmarks/architecture/run_development.py`; its
SHA-256 and both executing source-file hashes are recorded in the companion
JSON; `source_commit` alone does not contain every edited prototype state. The candidate catalogue contains
three 8-bp monomers. Two repeated read strings per case exercise the interface;
they are **not independent biological molecules**. No real read anchoring,
basecalling errors, assembly comparison tool, held-out set or physical copy
truth was evaluated.

Command in `tandemx-dev`:

```bash
python -m benchmarks.architecture.run_development \
  --output docs/logs/m2_exact_development_20260916.json
pytest -q tests/unit/test_architecture_prototype.py
```

The first seven-case run found four of four planted differences, with no false positives
in three planted negative controls. An equal-input, length-only read/assembly
baseline found one of four differences and missed three equal-length changes.
This is a deliberately small positive-control challenge built alongside the
prototype; its separation is useful for regression, **not** an estimate of
accuracy or a Methods advantage. The unit tests also cover a substitution,
insertion, cyclic-equivalent catalogue rejection, and mixed-molecule evidence.
Independent hostile review found that treating a complete left-flank-anchored
label path as cyclically interchangeable missed phase-relative rearrangements
(`ABAC` vs `ACAB`). The code now normalizes the name of a repeated HOR unit
but compares the complete ordered copy path relative to the verified left
flank; tests reproduce this case and `ABAB` vs `BABA`. The seven-case run was
repeated after correction. These new adversarial cases were initially tests,
not part of its seven-case tally.

The development challenge was then expanded to 11 cases to include HOR
rearrangement, monomer deletion, monomer duplication and HOR compression.
The first execution of these new cases returned 6/8 planted differences;
deletion and duplication were `unresolved` because the edited assembly no
longer had a periodic HOR unit. The code now permits a fully decomposed,
unambiguous nonperiodic assembly to be compared as an ordered monomer path.
It retains `assembly_hor_period_unresolved` in the warning and does not claim a
HOR for that assembly. The repeat run gives 8/8 planted differences and 3/3
negative controls; equal-input length-only gives 4/8 and 3/3. This remains
a designed exact-sequence regression challenge, not accuracy evidence. Focused
prototype tests: 18 passed in 0.92 seconds.

A second hostile example exposed a first-copy template bias: `CBABABAB`
originally selected a four-label unit despite having one variant in a
two-label `AB` unit. The prototype now estimates each periodic position from
all copies and prefers the shortest unit at equal mismatch count. Tests cover
first- and last-copy variants. Columns with tied modal labels retain
`template_ambiguous=true`; their proposed variant identity is not treated as
an established ancestral state. An ambiguously decomposed assembly is not
scored as supported concordance or discordance.

The prototype only accepts pre-trimmed intervals of at most 4,096 bp and up to
16 supplied monomers of at most 64 bp. It does not discover monomers from raw
reads, establish unique flank anchors, verify molecule independence, handle
ambiguous bases, phase a heterozygote, or infer megabase arrays. An explicit
40-million-cell work estimate rejects expensive exhaustive cases. Unresolved
decompositions and mixed molecules have explicit states. A future controlled
collapse benchmark must supply independent locus truth and compare the same
assembly+reads input against an external mapping audit before this path can be
considered for production.
